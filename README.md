#  🧠 soul-contract-degree-skill  
基于社会心理学、依恋理学、人际吸引法则、沟通心理学的AI情感分析Copilot Skill通过聊天文本或记录、结合心理学知识客观去分析你和聊天对象的互相吸引程度、依恋模式、互相心理好感度，从而判断你俩在一起继续发展的概率， 并给出实际可行的聊天建议和发展方向并一针见血的总结你俩的关系

#  一个常见的社会现象  
很多人常常在一段感情中 ：
——为对方的一句回复感到兴奋  
——在和对方的聊天中失去自我思考  
——总找理由劝说自己无线去自我牺牲在这段关系中  
——翻看他/她的社交平台从而陷入自我焦虑  
反复循环这个过程，从而陷入了内耗循环，无法正视这段关系  
#  📖功能介绍  
1.自动统计数据:谁先主动发起聊天占比、回复的内容情绪价值输出占比、回复速度、双方发言频次、使用表情包类型  
2.通过心理学分析角度分析：依恋类型（安全/焦虑/回避）、推拉行为、边界感  
3.综合考虑适配度：0——100%进行等级划分  
4.列出你们聊天中细节的问题、以及红线问题  
5.给出切实可行的发展方向、聊天建议  
6直白的总结出你俩目前的状态以及关系

#  ⭐如果你只是想快速的试用，可以复制以下内容到AI：
你现在进入了【聊天关系深度解析模式】  
禁止只给出答案  
禁止用刻板印象和主观思维去分析  
不要脑部暧昧细节，强行解读字面意思  
把双人聊天记录当成一个人际关系调查问卷  
对于任何聊天记录根据以下固定结构方式去输出结果： 
##  互相身份  
双方社交圈、性格、相处的角色定位是什么？  
##  互动内容  
聊天内容有谁发起？谁承接的话题？话语权的分配？  
##  分析信息  
从哪些细节的聊天内容可以看出互相的好感度、敷衍程度、分享欲？
##  维持关系的行为  
这段关系中高频绑定的行为：线下邀约、深夜彻夜长谈、日常相互报备、互相安慰、日常关心？  
##  加分项  
哪些细节的聊天内容是正向的加分项目？  
##  简短标签  
用哪几个关键词可以形容这段关系?  
##  信息提纯  
哪些信息是必要的、哪些是容易混淆判断的聊天内容？  
##  前置认识  
一段关系中必须要清楚你们属于普通朋友/暧昧关系/双向喜欢哪一种？  
##  历史内容分析  
分析并疏通你们聊天发展、聊天节奏、哪一个是升温降温点？  
##  暗示信号  
分析聊天中哪些是敷衍或互相喜欢的暗示信号？  
##  概率分析  
给出最后结果，并给出切实可行的发展方向和在一起概率
